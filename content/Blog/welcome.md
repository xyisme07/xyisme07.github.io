这是用 [Quartz](https://quartz.jzhao.xyz/) 搭建的静态博客。写作在 Obsidian 完成，推送到 GitHub 后由 GitHub Pages（Actions 自动构建）部署上线。

## 这个博客写什么

- 个人投资方法论记载
- 个人春秋笔路
- 心路历程-我的路
- 其他认可的摘要

## 它怎么运作

1. 在 Obsidian 的 `Blog/` 文件夹里写作（已用软链接接好）
2. 推送到 GitHub 的 `main` 分支
3. GitHub Actions 自动构建并发布到 GitHub Pages
